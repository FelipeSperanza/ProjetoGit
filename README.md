Repositório criado para acompanhar meus estudos práticos com base no livro “Controlando Versões com Git e GitHub”. O projeto reúne exercícios, comandos e exemplos desenvolvidos ao longo dos capítulos, com o objetivo de aprender e praticar o controle de versão, o gerenciamento de repositórios locais e remotos, o uso de branches e a colaboração com o GitHub.

Este repositório faz parte da minha jornada de aprendizado em Git e GitHub, registrando minha evolução e consolidando os conhecimentos adquiridos na prática.
